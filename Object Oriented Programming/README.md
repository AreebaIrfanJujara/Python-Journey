Multiple Inheritance
1. Create classes Printer and Scanner. Create a class AllInOne that can print and scan using
multiple inheritance.
2. Create classes Singer and Dancer. Create a class Performer that inherits from both.
3. Create classes Writer and Artist. Create a class Designer that inherits features from both
classes.
4. Create classes Camera and Phone. Create a class SmartPhone that inherits from both.

   
Multilevel Inheritance
1. Create a class hierarchy: Animal → Mammal → Dog and call methods from all classes.
2. Create classes Person → Employee → Manager and display details at each level.
3. Create classes Vehicle → Car → SportsCar and add one method in each class.
4. Create classes LivingThing → Animal → Cat and demonstrate inherited methods.
5. Create classes School → Teacher → HeadTeacher and display information from all
classes.

Hierarchical Inheritance
1. Create a parent class Shape and child classes Circle and Rectangle.
2. Create a parent class Vehicle and child classes Car and Bike.
3. Create a parent class Person and child classes Student and Teacher.
4. Create a parent class Animal and child classes Dog and Cat.
5. Create a parent class Account and child classes SavingsAccount and CurrentAccount.
   
Hybrid Inheritance

1. Create a hybrid inheritance structure using classes Person, Student, Teacher, and
TeachingAssistant.
2. Create classes Animal, Bird, Flyer, and Bat using a combination of multilevel and multiple
inheritance.
3. Create classes Device, Computer, Printer, and SmartPrinter using hybrid inheritance.
4. Create classes Employee, Developer, Tester, and TeamLead combining multiple and
multilevel inheritance.
5. Create a program where Student inherits from Person, and Monitor inherits from both
Student and Leader.
